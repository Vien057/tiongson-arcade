TIONGSON ARCADE — MOCK WEBSITE
================================

Open index.html in a web browser to view the mock website.

This is a static presentation website for the THC 212 Practice Application.
It uses the Tiongson Arcade brand promise and pricing ranges from the group's
provided DOLA AI script.

Included sections:
- Hero / waterfront introduction
- Brand promise
- Story / local knowledge
- Signature dishes
- Dining experience pricing
- Guest care and respect
- Waterfront gallery
- Closing call-to-action

No real booking, payment, or customer-data functionality is connected.
